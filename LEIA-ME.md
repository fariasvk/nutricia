# NutricIA v15.1 — Catálogo mais limpo

Este pequeno ajuste remove textos repetidos do catálogo de referência. O número de 299 produtos aparece uma única vez, no título. O contador de resultados só aparece após pesquisar. O aviso técnico só é exibido quando houver erro ou consulta nutricional.

## Instalação
1. Extraia o ZIP.
2. Abra o GitHub `fariasvk/nutricia` > Add file > Upload files.
3. Envie somente `index.html`, `app.js` e `sw.js` para a raiz, substituindo os anteriores. Faça Commit.
4. Abra o site e atualize com Ctrl+Shift+R (ou em aba anônima).

Não precisa alterar o Cloudflare e nenhuma informação dos 299 produtos foi modificada.
