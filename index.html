🔬 Relatório Científico & Fundamentação

Painel explicativo do projeto acadêmico NutricIA desenvolvido para apresentação na Feira de Ciências.

Objetivo do Projeto

O NutricIA foi desenvolvido para promover o letramento nutricional através da análise comparativa e transparente de rótulos de alimentos industrializados, utilizando dados abertos e regras oficiais de rotulagem.

Fontes de Dados & Metodologia

As consultas em tempo real são realizadas na API colaborativa internacional Open Food Facts. O projeto utiliza diretrizes da TBCA (USP) e normas da Anvisa (RDC 429/2020) para fundamentação conceitual.

Limitações & Ressalvas Acadêmicas

  • Campos ausentes na API aparecem estritamente como "Não disponível" e não são convertidos para zero.
  • O índice IAC é um modelo matemático simulador para fins didáticos e não substitui diagnósticos clínicos.
  • A Anvisa e a TBCA não possuem APIs públicas e abertas de consulta de produtos por código de barras; suas normas são aplicadas de forma conceitual.
