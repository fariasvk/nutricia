Relatório científico

Objetivos, fontes e limitações do NutricIA para a Feira de Ciências.

Objetivo

Promover o letramento nutricional, ajudando a comparar informações de rótulos de alimentos industrializados.

Fontes

A consulta por código de barras usa a base colaborativa Open Food Facts. Os dados dependem do que está cadastrado nessa base e precisam ser conferidos no rótulo.

Limitações e transparência

  • Dados ausentes são mostrados como “Não disponível”; não significam zero.
  • O IAC é uma fórmula simulada para fins escolares, não um índice oficial nem recomendação médica.
  • Produtos de demonstração são fictícios, sinalizados como tal e excluídos das respostas com dados reais da assistente.
  • Produtos cadastrados ou corrigidos manualmente são dados do usuário e não têm verificação externa automática.
  • O banco fica no dispositivo/navegador e não é sincronizado automaticamente entre aparelhos.
